## Project Overview

Jimmy is a queue-centric iOS podcast app built with Swift/SwiftUI. It targets iOS 27+ and uses Xcode 27.

`project.yml` is the source of truth for the Xcode project; `Jimmy.xcodeproj` is generated by XcodeGen and is not checked into git (run `make project` or `make bootstrap` to generate it).

## Build Commands

**Bootstrap** (check toolchain, install XcodeGen if needed, generate the project):
```bash
make bootstrap
```

**Build the project:**
```bash
make build
```

**Run tests:**
```bash
make test
```

**Lint:**
```bash
swiftlint --config .swiftlint.yml
```

Use the `make` targets rather than calling `xcodebuild` directly, and don't use workspace files.

`make test` and `make run` use the `SIM` simulator (default `iPhone 17 Pro`). On a machine whose only iOS 27 runtime
supports just the iPhone Duo device type, pass that simulator instead: `make test SIM="Folio Duo"`
(`xcrun simctl list devices available` shows what exists).

## Simulator Testing

Beyond compilation and unit tests, you can **run the app in the iOS Simulator** to visually verify changes. Use the convenience target/script or run commands individually.

**Full cycle (build → install → launch → screenshot):**
```bash
make run
# or: ./scripts/run_in_simulator.sh
```
Then use the `Read` tool on the printed screenshot path to view it inline.

**Individual commands:**
```bash
# Install & launch (after building)
APP_PATH=$(find build/DerivedData/Build/Products/Debug-iphonesimulator -name "Jimmy.app" -maxdepth 1 | head -1)
xcrun simctl install booted "$APP_PATH"
xcrun simctl launch booted com.chenkahana.Jimmy

# Take a screenshot (then Read the file to view it)
xcrun simctl io booted screenshot /tmp/jimmy_screenshot.png

# Terminate the app
xcrun simctl terminate booted com.chenkahana.Jimmy

# Deep link testing
xcrun simctl openurl booted "jimmy://queue"
xcrun simctl openurl booted "jimmy://library"
xcrun simctl openurl booted "jimmy://settings"
xcrun simctl openurl booted "jimmy://discover"

# Dark mode toggle
xcrun simctl ui booted appearance dark
xcrun simctl ui booted appearance light

# Accessibility contrast testing
xcrun simctl ui booted increase_contrast enable
xcrun simctl ui booted increase_contrast disable

# Inspect app data container (database, files)
xcrun simctl get_app_container booted com.chenkahana.Jimmy data

# App info
xcrun simctl appinfo booted com.chenkahana.Jimmy
```

| Item | Value |
|------|-------|
| Bundle ID | `com.chenkahana.Jimmy` |
| Simulator | iPhone 17 Pro |
| URL scheme | `jimmy://` |

## Architecture

**Clean MVVM with layered architecture:**

- **Presentation** (`Jimmy/Views/`, `Jimmy/Presentation/ViewModels/`) — SwiftUI views and `@Published` ViewModels
- **Domain** (`Jimmy/Domain/`) — Use cases, repository protocols, domain stores
- **Data** (`Jimmy/Data/`) — Concrete repository implementations
- **Services** (`Jimmy/Services/`) — 80+ singleton services (`.shared` pattern) for database, audio, networking, etc.
- **Infrastructure** (`Jimmy/Infrastructure/`) — CarPlay integration
- **Utilities** (`Jimmy/Utilities/`) — Parsers (OPML, Apple, Google Takeout, Spotify), extensions, caching

**Entry point:** `Jimmy/JimmyApp.swift` — initializes critical services (DIContainer, DatabaseManager, AudioPlayerService) synchronously, defers non-critical services to background tasks.

**DI:** `Jimmy/DependencyInjection/DIContainer.swift` manages service lifecycle. Most services use the singleton `.shared` pattern.

**Database:** GRDB.swift (v6.29.3+) for SQLite — managed by `DatabaseManager.shared`.

**Networking:** `UnifiedNetworkService` with three-tier caching (memory → disk/GRDB → network).

**SPM Package:** `Package.swift` defines `JimmyUtilities` library exposing parsers and models for unit testing outside Xcode.

## Key Conventions

- **Concurrency:** Swift async/await throughout. All UI code annotated with `@MainActor`. Background work uses `Task.detached(priority: .background)`.
- **UI:** 100% SwiftUI for views. UIKit used only for `StandardTabBarController` (tab bar) and CarPlay controllers.
- **File naming:** `*Service.swift` for services, `*ViewModel.swift` for view models, `*View.swift` for views.
- **SwiftLint:** Enforced via `.swiftlint.yml` with strict opt-in rules including `force_unwrapping`, `force_try`, and `implicitly_unwrapped_optional`. Avoid force unwraps and force tries.

## Testing

- **Unit tests:** `Tests/JimmyTests/` — parser tests, feature flag tests, accessibility tests, state management tests
- **UI tests:** `Tests/JimmyUITests/` and `JimmyUITests/`
- **CI quality gates:** 70% minimum coverage, 10 min unit test timeout, 20 min UI test timeout

## Dependencies

- **GRDB.swift** — SQLite database (only SPM dependency)
- **Firebase** — Analytics and crash reporting (via `GoogleService-Info.plist`)
- **System frameworks:** AVFoundation, WidgetKit, MediaPlayer, CarPlay

## CI/CD

GitHub Actions workflows in `.github/workflows/`:
- `ci.yml` — main pipeline (build validation, tests, rollback triggers)
- `code-quality.yml` — SwiftLint, memory analysis, architecture complexity
- `performance-monitoring.yml` — launch time, memory, build time, binary size
- `regression-detection.yml` — cross-branch comparison

Build validation scripts live in `scripts/` (38+ shell scripts for build validation, regression detection, rollback triggers).
