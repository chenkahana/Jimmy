# Getting help

- **Something isn't working:** open a [bug report](https://github.com/chenkahana/Jimmy/issues/new?template=bug_report.yml).
  Include your device, iOS version and Jimmy version (Settings › About).
- **An idea or request:** open a [feature request](https://github.com/chenkahana/Jimmy/issues/new?template=feature_request.yml).
- **A security problem:** don't post it publicly; see [SECURITY.md](SECURITY.md).
- **Privacy questions:** read the [privacy policy](docs/privacy.md).

## Common questions

**A podcast feed won't refresh.** Check that you're connected to the internet and that the feed URL is correct. If the host has blocked access, the feed may require authentication.

**Where is my library stored?** All podcast data (subscriptions, queue, progress, downloads) is stored on your device in a local SQLite database. Nothing is uploaded to any server.

**Can I export my subscriptions?** You can share an OPML file of your subscriptions. Export via the app's share feature or the podcast search interface.
